# نظام البنك — تسجيل الدخول والصلاحيات — C++ Console App 🏦🔐

تطوير لنظام البنك: صار البرنامج كامل خلف شاشة تسجيل دخول، وكل عملية محكومة بنظام صلاحيات حسب دور المستخدم — مبني بلغة ++C، وبيانات العملاء والمستخدمين محفوظة بملفات نصية.

> المشروع الأول من كورس **Algorithms & Problem Solving Level 4** (الكورس الثامن من خارطة الطريق للدكتور محمد أبو هدهود).

## المميزات

- كل شي من نظام البنك الموسّع: CRUD كامل للعملاء، إيداع، سحب (ما بيسمح تتجاوز رصيدك)، وتقرير إجمالي الأرصدة
- **شاشة تسجيل دخول** — البرنامج بيبلش بطلب اسم مستخدم وكلمة مرور قبل ما يعرض أي قائمة
- **صلاحيات حسب الدور** — كل مستخدم بيتحدد إله مجموعة قدرات محددة (عرض العملاء، إضافة، حذف، تعديل، بحث، معاملات، إدارة المستخدمين) أو صلاحية كاملة؛ أي عملية خارج صلاحياته بتنرفض برسالة "Access Denied" واضحة
- **قائمة إدارة المستخدمين** — إضافة، عرض، بحث، تعديل، وحذف حسابات الموظفين، كل وحد بصلاحياته الخاصة، محفوظة بملف منفصل عن بيانات العملاء

## أول تشغيل — لازم حساب أدمن أساسي

ملف `UserName.txt` بيبلش فاضي، وإنشاء مستخدم جديد يحتاج إنك أصلاً مسجل دخول بصلاحية إدارة المستخدمين — يعني أول حساب لازم يتضاف يدوياً قبل ما يصير فيك تستخدم البرنامج.

أنشئ ملف `UserName.txt` جنب البرنامج بسطر واحد، بنفس الصيغة يلي البرنامج نفسه بيكتبها (مفصولة بـ `#//#`):

```
admin#//#admin123#//#-1
```

الرقم `-1` هو قيمة "صلاحية كاملة". غيّر اسم المستخدم وكلمة المرور بعد ما تدخل.


## طريقة التشغيل

```bash
g++ main.cpp -o bank_system_auth
./bank_system_auth
```

> البرنامج يستخدم أمر خاص بنظام Linux (`system("clear")`) لمسح الشاشة، فأفضل تشغيل له على Linux أو macOS.

## المفاهيم المطبّقة

- صلاحيات بنظام Bitmask — كل قدرة عبارة عن راية (flag) لوحدها بقوى الاثنين (1، 2، 4، 8، 16، 32، 64)، بتتجمع بـ `+=` وقت منح الصلاحية وبتتفحص بـ `&` وقت التحقق — نفس التقنية يلي تستخدمها أنظمة التحكم بالصلاحيات الحقيقية
- بوابة مصادقة قدام البرنامج كامل، مع المستخدم المسجّل محفوظ بـ struct عام واحد بيرجعله كل فحص صلاحية
- إعادة استخدام نفس الـ struct ونفس صيغة السطر `#//#` لحفظ نوعين مختلفين من السجلات — عملاء ومستخدمين — بملفين منفصلين
- Recursion للتنقل بين القوائم وكمان لإعادة محاولة بحث فشل
